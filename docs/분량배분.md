## 공민재 — 게시판 (커뮤니티 3종)

서비스의 핵심 기능. 세 페이지가 하나로 이어집니다.

**묶은 이유:** 셋 다 같은 api/posts/를 사용

### community.html — 커뮤니티 목록

게시글을 카드로 나열하는 게시판 메인.

- 게시글 목록을 카드 형태로 표시
- 카테고리 필터 (갤러리 / 레시피 / 자유)
- 검색 (키워드로 게시글 찾기)
- 페이지네이션

```
GET  /api/posts?page=1&size=12      목록
GET  /api/posts?category=recipe     카테고리 필터
GET  /api/posts?keyword=연어         검색
```

### post-detail.html — 게시글 상세

목록에서 글을 클릭하면 열리는 상세 화면.

- 게시글 본문·이미지 표시
- 좋아요 (눌렀다 취소)
- 댓글 목록 보기
- 댓글 작성·삭제

```
GET     /api/posts/:postId                    상세 조회
POST    /api/posts/:postId/like               좋아요
GET     /api/posts/:postId/comments           댓글 목록
DELETE  /api/posts/:postId/comments/:id       댓글 삭제
```

### post-write.html — 글 작성 / 수정 

새 글을 쓰거나 기존 글을 고치는 에디터.

- 작성 / 수정 모드 자동 구분 (`?postId=` 있으면 수정)
- 이미지 업로드 + 미리보기
- 태그 입력 (Enter 로 추가)
- 글자 수 카운터

**주의:** 이미지 업로드는 `FormData` 를 쓰고 `Content-Type` 을 직접 넣지 마세요.
boundary 가 빠져 서버가 파싱하지 못합니다. `Api.upload()` 를 사용하세요.

## 김나원 — 사료 (2종)

**묶은 이유:** 같은 `/api/feeds` 데이터를 사용하고 `feedId` 로 목록↔상세가 연결

### feed-recommend.html — 사료 추천 목록

개에 맞는 사료를 추천하는 목록.

- 사료 목록을 카드로 표시
- 필터 (품종·나이·체중으로 걸러내기)
- 정렬 (가격순 등)

```
GET  /api/feeds?breed=&age=&weight=   조건별 사료
GET  /api/breeds                     품종 목록 (필터용)
```

### feed-detail.html — 사료 상세 

사료 하나를 클릭하면 열리는 상세 정보.

- 사료 이름·브랜드·가격·이미지
- 영양 정보 표시 (단백질·지방 등)

```
GET  /api/feeds/:feedId               사료 상세
```

**주의:**
- 가격·칼로리 같은 숫자에 브랜드 색(주황)을 쓰지 마세요. 클릭 링크로 오인됩니다.
- 영양정보가 JSON 문자열로 올 경우 `try / catch` 로 파싱하세요.

## 혜주 — 독립 페이지 (기술형 2종)

### health-record.html — 건강기록

강아지 건강을 기록하고 차트로 보는 대시보드.

- 체중 변화 차트 (Chart.js 라이브러리)
- 건강 기록 목록 (체중·식사량·배변·컨디션)
- 새 기록 추가
- 이상 징후 알림 (체중 급변 등)

```
GET   /api/pets/:petId/health/latest    최근 기록
GET   /api/pets/:petId/health/records   기록 목록
POST  /api/pets/:petId/health/records   기록 추가
GET   /api/pets/:petId/health/alerts    이상 징후
```

**주의:**
- Chart.js CDN 을 추가해야 합니다. (`layout.js` 뒤, 페이지 스크립트 앞)
- 차트를 다시 그릴 때 `chartInstance.destroy()` 를 먼저 호출하세요.
  안 하면 메모리 누수 + 툴팁이 중복됩니다.
- 건강 상태는 색만으로 구분하지 말고 `.status-chip`(색 + 도형 + 텍스트)을 쓰세요.
- 건강 화면 카피는 친근한 어투 대신 담백하게. ("체중이 12% 줄었어요")

### ai-chat.html — AI 채팅 (백엔드 대기)

"이거 먹여도 될까요?" 물어보는 AI 상담 채팅.

- 대화 목록
- 메시지 주고받기
- 사진 첨부 (식재료 분석용)

```
GET   /api/chats                     대화 목록
POST  /api/chats                     새 대화
GET   /api/chats/:chatId/messages    메시지 목록
POST  /api/chats/:chatId/messages    메시지 전송
```

**주의:**
- 백엔드 AI 가 준비돼야 테스트가 가능합니다. 백엔드 일정을 확인하고 마지막에 착수하세요.
- AI 응답에도 면책 문구가 필요합니다. ("AI 분석 결과는 참고 정보이며 수의학적 진단이 아닙니다.")
- AI 응답 문자열은 `textContent` 로 삽입하세요. (`innerHTML` 금지)

## 시작하기 전에

각자 아래 순서로 진행하세요.

1. 저장소 clone 후 최신 `main` 받기
2. [CONTRIBUTING.md](./CONTRIBUTING.md) 섹션 0 (협업 방식) 읽기
3. 자기 담당 브랜치 생성 — `feat/community`, `feat/feed-detail` 등
4. `_example-page` 3종을 복사해 페이지 파일 3개 생성
   (`페이지.html` → 루트, `styles/페이지.css`, `scripts/페이지.js`)
5. 파일 안의 `example` 을 담당 이름으로 치환
6. 기능 구현 후 PR 로 `main` 에 합치기

### 공통 필수 규칙 (자세한 내용은 CONTRIBUTING.md)

- `fetch` 직접 호출 금지 → `Api.get / post / upload` 사용
- 사용자 입력은 `textContent` 로만 삽입 (`innerHTML` 금지)
- 폼은 `submit` 이벤트에 `event.preventDefault()`
- 상세 페이지 쿼리 파라미터 이름 준수 — `?postId=`, `?feedId=`
- 공통 파일(`variables.css`, `layout.js` 등) 수정 금지
- `@media` 추가 금지 (데스크톱 전용)
