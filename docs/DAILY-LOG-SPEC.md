# 통합 기록 페이지 (daily-log.html) 설계

diet.html(식단분석) + health-record.html(건강기록)을 하나로 합친 페이지.
날짜별로 식단·체중·배변·특이사항을 기록하고, 우측에서 건강 지표를 한눈에 본다.

검색 키워드: 달력, 기록, 식단, 건강, 체중, 비만도, 급여량, 데일리로그

**상태: 구현 완료.** `daily-log.html` / `styles/daily-log.css` / `scripts/daily-log.js`
diet.html, health-record.html 과 관련 js/css 는 제거되었습니다.
이 문서는 설계 근거로 계속 보관합니다 (엔드포인트 규약은 `docs/INTEGRATION-CHECKLIST.md` 3번 섹션이 최신본).

---

## 1. 레이아웃 (1024px 기준 2단)

```
┌──────────────────────────┬────────────────┐
│  월 단위 달력              │  체중 카드      │  ← 클릭 시 모달(주/월/년 추이)
│  (날짜칸에 색점 표시)      │  비만도 카드    │  ← 품종 표준 대비 +/-
│                          │  급여평균 카드   │  ← 최근 7일 평균, 표준 대비 +/-
├──────────────────────────┴────────────────┤
│  [선택한 날짜] 상세 (달력 아래 펼침)          │
│   - 식사 기록 (시간별, 자유 추가)            │
│   - 체중 / 배변 / 특이사항                   │
└────────────────────────────────────────────┘
```

## 2. 달력

- 월 단위, 이전/다음 달 이동
- 각 날짜칸 하단에 **색점(dot)**:
  - 테라코타 점 = 식단 기록 있음
  - 빨강 점 = 배변 이상(무름/설사)
  - 회색 점 = 특이사항 메모 있음
- 오늘: 테두리 강조 / 선택일: 채운 배경
- 날짜 클릭 → 아래 상세 영역 갱신

## 3. 하루 상세 (선택일)

### 식사 기록 (자유 추가)
- "+ 식사 추가" 버튼으로 (시간 + 음식들 + 사진) 세트를 원하는 만큼
- 시간대 자동 정렬 (아침→저녁)
- 음식은 기존 diet.js 음식 검색 모달 재사용 (/api/food-items, 급여 가능 여부)
- 음식 선택 시 칼로리·영양성분 자동 계산 (서버 계산값)
- 이미지: 한 끼당 최대 4장, 로컬 미리보기 (실제 업로드는 백엔드 연동 시)

### 체중 / 배변 / 특이사항 (하루 1개)
- 체중: 숫자 입력 (kg)
- 배변: 4버튼 빠른 선택 [정상 / 딱딱함 / 무름 / 설사] + 메모(선택)
  - 브리스톨 척도 개념 차용 (3~4형=정상), 일상 기록용으로 단순화
- 특이사항: 자유 메모

## 4. 우측 지표 카드 3종

### 체중 카드
- 최신 체중 표시 + 클릭 시 모달: 주/월/년 탭 전환 Chart.js 추이 차트

### 비만도 카드
- 품종 표준체중 대비 현재 체중으로 판정
- 표시: 저체중 / 적정 / 과체중 (색: 파랑 / 초록 / 빨강)
- 판정: 현재체중 / 품종표준 → 85% 미만 저체중, 85~115% 적정, 115% 초과 과체중
- 품종 데이터 없으면(믹스견/기타) "표준 없음, 체중 추이만 참고" 안내

### 급여평균 카드
- 최근 7일 하루 평균 섭취 열량 표시
- MER(하루 필요 열량) 대비 +/- 판정
  - MER = RER × 활동계수, RER = 70 × 체중^0.75
  - 활동계수 기본 1.6 (중성화 성견 표준) — 추후 반려견 프로필에서 받아 조정
  - 평균 열량 / MER → 90% 미만 부족(파랑), 90~110% 적정(초록), 110% 초과 과다(빨강)

## 5. 표준 데이터 (breed-standards.js)

- 주요 품종 표준체중 + 계산 공식을 프론트 상수로 (mock)
- **[확인 필요] 백엔드 연동 시 /api/breeds/standards 로 대체**
- 계산 공식은 수의학 표준(RER/MER)이라 백엔드도 동일하게 써야 함

## 6. 백엔드 연동 지점 (전부 [확인 필요])

```
GET  /api/pets/:id/daily-log?date=            그날 식단+건강 기록
POST /api/pets/:id/daily-log                  기록 저장 (하루 전체를 통째로 보냄)
GET  /api/pets/:id/daily-log/summary?month=   달력 점 표시용 월 요약 (신규, 구현 중 추가)
GET  /api/pets/:id/daily-log/calorie-stats?days= 최근 N일 평균 섭취열량 (신규, 구현 중 추가)
GET  /api/pets/:id/weight?range=week          체중 추이 (주/월/년)
GET  /api/food-items?keyword=                 음식 검색 (기존)
GET  /api/breeds/standards                    품종 표준체중 (신규, 아직 미호출 - breed-standards.js mock 사용 중)
```
현재는 전부 mock 데이터로 화면 동작 (404 는 정상, 빈 상태로 처리됨).
요청/응답 상세 필드는 `docs/INTEGRATION-CHECKLIST.md` 3번 섹션 참고. 연동은 백엔드 담당.

`daily-log/summary`, `daily-log/calorie-stats` 는 애초 설계서(위 5개)에는 없었으나
달력 점 표시와 급여평균 카드 구현 중 필요해 추가된 엔드포인트입니다.
