# _examples

새 페이지를 만들 때 복사해 쓰는 견본입니다. **서비스 코드에 포함되지 않습니다.**

사용법: 세 파일을 아래 위치로 복사한 뒤 파일 안의 `example` 을 담당 이름으로 치환하세요.

```
_examples/_example-page.html  ->  <페이지명>.html        (루트)
_examples/_example-page.css   ->  styles/<페이지명>.css
_examples/_example-page.js    ->  scripts/<페이지명>.js
```

검색 키워드: 예시, 견본, 시안, 템플릿, 새 페이지 만들기
